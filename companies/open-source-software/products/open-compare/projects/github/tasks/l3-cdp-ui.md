先 skill({ name: "product-qa" })。维护本项目 qa-checklist.md。本任务是渲染层的默认实机验收入口：免设备排队，用浏览器/CDP 驱动 OpenCompare 的 renderer，不再为渲染层路径占用 computer。

启动方式：用 `--user-data-dir=<临时目录> --remote-debugging-port=<空闲端口>` 启动被测包（仓库内 `release/mac-arm64/OpenCompare.app`，或按需 `pnpm build` 的新包），通过 `http://127.0.0.1:<port>` 的 CDP 驱动真实窗口里的 DOM；锁屏环境用 `Emulation.setFocusEmulationEnabled`。真实文件/真实目录，不用内置样本。

本任务覆盖（每场按 brief 挑 2–3 条，30 分钟墙钟）：
1) 冷启动即对比工作台：主入口为打开文件/打开文件夹与顶栏常驻「新建对比」，样本仅可跳过辅助入口；
2) 真实两目录对比、五段过滤、展开/滚动/选中后双击差异项下钻到文件级并逐级返回，往返多次状态不丢；
3) 顶栏新建对比粘贴真实左右路径（空格/中文/Unicode/引号/~/相对路径）免弹窗建会话，非法输入不建 tab；
4) 多会话切换、关闭、未保存提示，全关回空首屏可再开，不刷新不重启；
5) 路径会话内编辑后的脏标记与 UI 状态（落盘与原生保存对话框属 computer 场，不在此重复）；
6) 目录对比 HTML 报告导出：使用 brief 指定的真实大目录对照对建目录对比会话，点目录视图工具栏常驻「导出 HTML 报告」落盘 `.html`；取消保存不写文件、无半成品、无成功提示；产出的 `.html` 无脚本执行、无外链 CSS/字体/图片、无 `http(s)://` 资源；产物 ≤10 MB / ≤200,000 行且报告内明示「已展示 N / 原始 M（已截断）」与原始行数；四态计数与界面图例数字逐项相等、版本号等于当前应用版本、报告 `<html lang>` 与当前界面 `document.documentElement.lang` 一致、顶部固定「由本机生成，分享前自查路径」且默认产物内不出现本机绝对路径。

开工即建 digest.md 骨架，每验完一条立即追加结论+证据路径；产品行为失败才 needsOwner: true，环境不就绪记 blocked + needsOwner: false。不要在代码仓建用例。

【场次纪律】① 一场 = 一个 brief + 2–3 条明确验收项，30 分钟墙钟硬上限，到点没验完就写现状 + 止损行收场，不许「重开一场代替收尾一场」；continue 只允许一次且必须先补齐上一场未落地的结论。② 每完成一条腿/阶段立刻在 digest 追加一行（时刻/阶段/实测/判定），digest 静默超过 20 分钟视为故障：先回填再干活。③ 同一 commit 上已出结论的路径不得重开；新场 digest 首行必须写清本场覆盖哪条未验项与相对上一场的差异。④ 夹具口径一次定死：禁止「先缩水跑一遍、再补规模跑一遍」。⑤ 同一 task 每天手动起场 ≤3，各场对应互不相同的未验项，第 4 场起先报负责人。⑥ 同一时段只允许一场 CDP 验，验完即停，不为「再确认一次」重起。
