# 首发样板频道 · 14 天方向赛马目标

这是矩阵里第一个用来「跑方向」的频道。14 天内不追求爆发，只回答一个问题：**这个方向值不值得继续加注？**

## 起跑前必须确认

- [ ] 垂直赛道：服务哪一类人、解决什么问题
- [ ] 目标平台：首轮主攻的 1–2 个平台
- [ ] 账号人设：我是谁、跟读者的关系、绝不扮演什么角色
- [ ] 内容支柱：2–3 个可持续输出的主题
- [ ] 转化口径：14 天结束时用什么真实数据判断方向成立

以上结论写入本文件与 `AGENTS.md` 后，清空 `code/` 下所有占位内容。

## 14 天内的节奏

1. **第 0 天**：跑一次 `projects/radar/tasks/public-signal-scan.md`，拿到第一批真实公开信号。
2. **每天**：`studio/daily-topic-pitch` 产出选题，负责人拍板后按需生成多平台成品包。
3. **第 7 天**：做一次中间检查，只看真实互动与选题命中率，不急着下结论。
4. **第 14 天**：`growth/weekly-channel-retro` 汇总真实数据，给出「加注 / 保持 / 冻结」建议，交给矩阵总控周会决策。

## 判断标准（示例，按实际平台调整）

- **方向成立**：至少 2–3 条内容出现超出基线的真实互动，且评论区有明确的目标受众在提问或收藏。
- **样本不足**：内容量或互动量太小，无法判断，保持一个周期。
- **方向不成立**：持续输出后仍无目标受众响应，冻结该方向，换下一个。

## 诚实底线

没有真实数据就写「暂无数据」。禁止编造阅读量、粉丝数、转化率、爆款案例或用户评论。14 天的价值在于得到真实的「行或不行」，而不是把报告写好看。
