# 内容工坊（Studio）

这个项目把雷达信号变成可执行的内容，但**不替负责人拍板，也不擅自发布**。

- `tasks/daily-topic-pitch.md`：每天 10:00 读取同级 `radar` 项目的新信号（`reads.projects` 已声明只读授权），产出 2 个选题提案与切入角度，写进本项目 `pitches/`，等负责人确认。
- `tasks/multi-platform-draft.md`：负责人确认方向后，按需生成公众号长文、小红书图文卡与 X 推文串的完整成品包，写进本项目 `drafts/`；确认发布后归档到本项目 `published/`。

所有成稿落盘前按名称加载公司级技能 `brand-voice` 自检。所有产物都落在本项目工作目录内，不通过相对路径写入其它目录。没有真实信号时，如实写「暂无可用信号」，不要凭空编选题。
