# 内容工坊（Studio）

这个项目把雷达信号变成可执行的内容，但**不替负责人拍板，也不擅自发布**。

- `tasks/daily-topic-pitch.md`：每天 10:00 读取 `radar` 的新信号，产出 2 个选题提案与切入角度，写进频道 `code/pitches/`，等负责人确认。
- `tasks/multi-platform-draft.md`：负责人确认方向后，按需生成公众号长文、小红书图文卡与 X 推文串的完整成品包，写进频道 `code/drafts/`。

所有成稿落盘前按 `../../../skills/brand-voice/SKILL.md` 自检。没有真实信号时，如实写「暂无可用信号」，不要凭空编选题。
