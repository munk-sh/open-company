# 矩阵总控（Matrix HQ）

这里是自媒体矩阵的顶层决策项目。它不写稿，只做三件事：

1. **比较**：按周汇总各频道 `growth` 项目的复盘结论，用统一口径看内容产出、真实互动与可得转化信号。
2. **决策**：对表现好的频道加注，对连续低效的频道先冻结、再按证据淘汰。
3. **沉淀**：把验证有效的标题钩子、开头结构与平台排版提取成全矩阵共享打法。

## 当前频道

- `flagship-channel`：首发样板频道，从 Day-0 空态开始，等待第一轮真实信号与复盘。

新增频道后，它的 `radar`、`studio` 与 `growth` 项目会随同作用域自动进入启动上下文的只读索引，`tasks/weekly-matrix-review.md` 按注入的 `growth/retros/` 路径取数即可，下一轮周会即进入比较；无需再手工维护跨项目读取声明。

`dashboard.html` 是只读的诚实空态看板。它只展示能从各频道复盘文件中核实的事实；没有真实数据时显示「暂无数据」，不编造任何指标。
