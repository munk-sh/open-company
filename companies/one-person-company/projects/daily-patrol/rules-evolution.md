# 规则与认知自进化库 (Rules Evolution)

本文件记录「一人公司」从日常运行、人类决策反馈与踩坑中提炼出的实战规则。

---

## 一、进化流程与生命周期

```
  [人类交互与决策反馈] ──> [提出建议 (PROPOSED)] ──> [3天运行观察] ──> [正式固化 (MERGED) 至 AGENTS.md]
                                   │
                                   └──> [若有反例/失效] ──> [废弃 (DEPRECATED)]
```

## 二、当前规则进化清单

### 1. 已合并至公司 AGENTS.md 的规则 (MERGED)

- **`RULE-MERGED-001` · Wealth 咨询报价硬闸**
  - **部门**：`wealth`
  - **生效日期**：2026-10-25
  - **规则内容**：所有技术咨询与外包服务方案，等效时薪（EHR）不得低于 ¥800/小时；低于该门槛或没有明确交付边界的方案，一律直接在初审时否决或建议转为数字商品。
  - **成效**：成功推掉 2 个无意义低价需求，专注高单价交付。

- **`RULE-MERGED-002` · Radar 零 Token 预检降噪**
  - **部门**：`radar`
  - **生效日期**：2026-10-28
  - **规则内容**：所有信源扫描必须由零 Token 的 `guards/*.mjs` 进行哈希或前置比对；无新增高优条目时静默退出，严禁因无信息而频繁唤醒 LLM。
  - **成效**：API 调用成本降低 73%，零噪音报警。
