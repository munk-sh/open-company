# 夜间复盘与规则进化指南（Rule Evolution）

本技能指导 `daily-patrol` 部门执行每日 21:00 晚间复盘任务。

---

## 一、复盘三步对账法

1. **第一步：今日 MIT 履约对账**：
   - 检查早晨制定的 3 项 MIT 的实际完成情况；
   - 标记为 `done`、`in_progress` 或 `blocked`；
   - 针对未完成或被阻断的事项，记录卡点原因（是外部等待、估时不足还是临时打岔？）。
2. **第二步：各部门产出与投入审计**：
   - **Radar**：今日新增了多少信源扫描？有无误报噪音？
   - **Brain**：消化了多少篇长文/火花？
   - **Studio**：已发出的内容数据反馈如何？撰写流程是否耗费人类过多修改时间？
   - **Wealth**：是否有新的账单导入？AR 有无延期风险？
3. **第三步：人类决策偏好提炼（核心价值点）**：
   - 检查人类今天在主页对话中的所有关键决策与否定；
   - 寻找重复出现的模式，将其转化为可操作的准则。

---

## 二、输出格式与落盘标准

输出保存于 `reviews/YYYY-MM-DD.md`，并同步更新 `journal/YYYY-MM-DD.md`。

```markdown
# 🌙 晚间复盘与进化 · 2026-11-04

> **本日总结**：3 项 MIT 达成 2 项，1 项正在推进；内容已成功发布；提炼 1 条 Studio 负向选题规则。

## 🎯 MIT 完成情况
- [x] **MIT 1 (财富)**：Cloudflare Workers 迁移咨询方案已发出（客户已确认收到）
- [x] **MIT 2 (工坊)**：已审阅并发布《为什么本地浏览器 Agent 正在替代 80% 的套壳 SaaS》
- [ ] **MIT 3 (雷达)**：DeepSeek-V3 本地量化服务线索竞品拆解（进行中，已完成 70%）

## 🔍 今日踩坑与洞察
- **Studio 环节**：初稿开头依然有“在当今快节奏的世界里”这类典型 AI 废话，人类不得不手动删掉第一段。必须在 Studio 的 prompt 与准则中严格禁止“在...的时代/背景下”这类开场白。

## 🧬 规则进化建议 (Proposals for AGENTS.md)
- **部门**：`studio`
- **规则编号**：`RULE-EVO-20261104-01`
- **描述**：所有文章与短文开头第一句禁止使用任何宏大背景式陈述（如“在当今人工智能迅猛发展的时代”），必须从具体的痛点场景或尖锐的数据结论直接切入。
- **状态**：`PROPOSED`（进入 3 天观察期）
```

---

## 三、落盘与更新命令

复盘完成后，运行：
```bash
node scripts/patrol-ctl.mjs review --date=YYYY-MM-DD
```
该命令会自动解析复盘结果，更新 `rules-evolution.md`，并将看板状态刷新为夜间模式。
