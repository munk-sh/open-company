# 📥 第二大脑 · 碎片投喂箱（`inbox/`）

这里是你的「零心智负担收件箱」。你不需要做任何排版整理，只管往里丢：

1. **最省事的投喂方式（推荐）**：
   直接在 Munk AI 主页右栏跟 **公司负责人（Company Owner）** 随口说：
   - *“把这个链接 `https://...` 收进第二大脑，我觉得里面讲单人 SaaS 定价那段很绝。”*
   - *“记一条灵光一现：现在做 AI 工具千万别做大而全的工作台，要切进某个具体职业每天必做的最后一步导出动作。”*
   - 负责人会自动按标准格式替你落盘到本目录（如果你急着看，负责人会当场唤醒 `inbox-digest` 立即提取网页正文并内化）。

2. **手动拖拽投喂**：
   你也可以随时把本地的 `.md`、`.txt`、会议录音转写稿、读书划线导出文件直接拖进 `inbox/` 文件夹。

---

## 自动清空机制（Inbox Zero）

- 守卫脚本 `guards/brain-inbox-guard.mjs` 每 2 小时以 **0 Token** 扫描一次本目录（自动忽略本 `README.md` 与 `archive/`）。
- 一旦发现新投喂文件，自动唤醒 `inbox-digest` 任务：提取链接正文 $\rightarrow$ 与既有认知碰撞 $\rightarrow$ 合入 `../topics/` 常青认知卡 $\rightarrow$ 提炼火花至 `../sparks.md`。
- 消化完成后，原始文件会自动移入 `inbox/archive/` 留档备查，保持 `inbox/` 永远清爽。
