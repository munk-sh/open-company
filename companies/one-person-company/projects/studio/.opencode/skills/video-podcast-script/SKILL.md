# Video & Podcast Script（口播逐字稿与动态分镜设计工艺）

很多创作者直接拿着公众号文章去录口播或做视频，结果念得舌头打结、画面像无聊的 PPT 翻页。
本技能解决两件事：
1. **把书面语改造成有呼吸、有重音的真人口语台词**；
2. **把抽象观点翻译成具体的「动态视觉隐喻分镜（`scenes.json`）」**，供后续 `worker` 加载 `hyperframes-motion-craft` 编写定制 SVG/GSAP 动画。

---

## 一、 书面语转真人口语的 4 条铁律

1. **砍掉所有书面连接词**：
   - 严禁出现 `因此`、`然而`、`综上所述`、`换言之`、`此外`；
   - 全部替换为真人口语：`所以你会发现`、`但最坑的是什么呢`、`说白了就是`、`还有一件事特别有意思`。
2. **单分句绝不超过 18 个字**：
   - 真人一口气自然说出的短句通常在 8–16 个字之间。用逗号/句号清晰切分，以便 `synth-tts.mjs` 自动拆成底部同步中文字幕（`cues`）和段内动画触发点（`fragments`）。
3. **前 3 秒截停钩子（Scene 1 必用）**：
   - 第一句必须直接抛出反常识暴论或惊人算账对比（如：*“如果你现在每天花超过两小时刷行业资讯，听我一句劝，马上停掉。”*）。
4. **中文视觉主信息规范（对齐 Munk 运营规范）**：
   - 口播是中文时，每一镜画面的主标题、节点词、对比标签必须使用**精炼中文**（单节点 ≤ 6–10 字），配合本机苹方字体与底部同步中文字幕。

---

## 二、 动态视觉隐喻设计（严禁静态文字罗列！）

在为 `video-forge` 生成 `src/video-studio/workspace/scenes.json` 时，每一镜（Scene）都必须写明 **`visualMetaphor`（针对本镜内容定制的动态图形演法）**：

| 常见叙事意图 | ❌ 严禁做成的平庸 PPT | ✅ 必须设计的定制动态隐喻 (`visualMetaphor`) |
| :--- | :--- | :--- |
| **讲「以前笨办法有多痛」** | 列出 1、2、3 三行痛点文字 | **故障链路图**：画 4 个串联节点，前 2 个绿灯，到第 3 步随语音突然变红闪烁并弹出耗时数字 `4.5h` |
| **讲「零成本过滤/漏斗」** | 写一句“脚本帮我过滤了 90% 噪音” | **拦截网动画**：左侧多个灰色噪点块冲向中间的荧光绿守卫线被挡住，只有 1 个高亮光点穿过防线点亮右侧大脑节点 |
| **讲「前后算账对比」** | 左右两段长文字说明 | **双栏算账仪表盘**：左卡暗红展示旧成本，说到转折句（`fragments[0]`）时右卡电光蓝/荧光绿亮起，数字从 `10h` 跳变到 `15m` |
| **讲「多步闭环架构」** | 放一张静态截图 | **SVG 动态生长拓扑图**：随口播每讲到一个环节，对应 SVG 连线（`drawSvgPath`）动态生长并点亮下一个模块节点 |

## 三、 `scenes.json` 标准交付结构

当需要进入 `src/video-studio/` 制作视频时，先调 `node scripts/studio-ctl.mjs init <slug> --aspect 9:16|16:9`，然后将分镜写入 `src/video-studio/workspace/scenes.json`：

```json
{
  "slug": "2026-11-04-zero-token-guard",
  "title": "一人公司的零成本情报防线",
  "aspect": "9:16",
  "theme": "dark-keynote",
  "voice": "zh-CN-YunxiNeural",
  "scenes": [
    {
      "id": "scene-1-hook",
      "kicker": "01 · STOP NOISE",
      "headline": "别再肉眼刷资讯了",
      "subhead": "95% 的热点只是在消耗你的注意力",
      "visualMetaphor": "上方密集红色焦虑气泡下压 -> 在 fragments[0] 处被一道绿色防线一键清空，亮出 3min 核心内参卡",
      "narration": "如果你现在每天花超过两小时刷行业资讯，听我一句劝，马上停掉。因为你刷到的百分之九十五的热点，都是在白白消耗你的脑力带宽。"
    }
  ]
}
```
写完 `scenes.json` 后，立即运行 `node scripts/synth-tts.mjs`，自动合成语音并算出每镜精确的 `startTime`、`duration`、`fragments` 与字幕 `cues`。
