# 每日选题提案池 (`pitches/`)

本目录存放由 `topic-pitch` 任务生成的每日选题提案（`YYYY-MM-DD.md`）。

## 运作机制
1. **先选角度，再动笔**：避免 AI 在你没拍板的方向上盲目生成几千字废稿。每次提案只精选 **2 个高张力切入角度**（绑定 `brain` 常青卡片与 `radar` 新鲜信号，套用 `.opencode/skills/angle-alchemy` 冲突模型）。
2. **如何拍板成稿**：
   - 看中某个提案后，直接对公司负责人说：*「写今天第 1 个选题，出公众号和小红书版本」*；
   - 负责人会自动带 `brief` 唤醒 `content-forge` 任务，将完整多平台成稿输出至 `../drafts/`。
